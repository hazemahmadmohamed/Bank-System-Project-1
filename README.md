Project Title: Bank System Project
Programming Language: C++

Overview:
This program is a simple yet efficient Bank Client Management System built using C++. It allows users to manage client data such as account numbers, names, PIN codes, phone numbers, and balances — all stored in a structured text file for persistence.

Core Features:

Show Client List: Displays all registered clients with their full details.

Add New Client: Adds a new client to the system and saves their data to the file.

Find Client: Searches for a client by account number and displays their information if found.

Delete Client: Removes a client record from the file after confirmation.

Update Client: Edits an existing client’s data directly within the file.

Reset All Clients: Clears all stored client data safely.

Welcome & Exit Screens: Includes formatted console screens for a professional user experience.

Key Advantages:

Uses file handling to store and retrieve data persistently.

Modular structure with clear, reusable functions.

User-friendly text-based interface.

Simple logic flow — easy to understand and extend.

Target Users:
This program is designed for students learning C++, especially those studying file handling, data management, and structured programming. It’s also suitable for anyone looking to understand how small database systems operate using text files.# Bank System Project 1
